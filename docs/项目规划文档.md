# 鑫源温控壁挂炉智能控制项目规划文档（用户资料对齐版）

## 1. 文档依据

本版规划基于以下用户资料重新整理：

- `docs/暖通智控.pdf`：用户提供的小程序原型图，共 22 页。
- `docs/壁挂炉需求文档.docx`：用户提供的功能需求文档。
- `docs/壁挂炉协议最新版本.xlsx`：用户提供的壁挂炉 4G 温控器 MQTT 协议表。
- `docs/项目规划文档.md`：前期生成的通用项目规划文档。

本版重点从“通用锅炉智能家居平台”收敛为“壁挂炉 4G 温控器微信小程序 + 师傅端 + 后台 + MQTT 设备接入平台”。

## 2. 项目定位

项目建设目标是为鑫源温控壁挂炉温控器提供一套完整的云端控制平台，包含：

- C 端微信小程序：家庭用户管理家庭、房间、设备，查看设备状态并远程控制壁挂炉温控器。
- 师傅端：安装/维修师傅查看被授权家庭和设备，处理邀请，进行授权期内的设备调试。
- 后台管理端：管理用户、设备、师傅、内容、协议参数、告警、报修和运营配置。
- 设备接入服务：基于 MQTT 接入壁挂炉 4G 温控器，处理设备上报、指令下发、回执、故障、OTA 和后台高级参数。

## 3. 用户角色

### 3.1 C 端家庭用户

家庭用户通过微信小程序使用系统。

主要能力：

- 登录/注册。
- 创建和管理家庭。
- 创建和管理房间。
- 添加、绑定、共享、删除设备。
- 查看设备状态。
- 控制开关机、童锁、目标温度、运行模式。
- 配置日计划、周计划。
- 查看温湿度曲线。
- 管理个人资料、消息、账号安全。
- 绑定师傅并临时授权调试设备。

### 3.2 家庭成员

家庭成员由家庭创建者邀请加入。

主要能力：

- 查看加入的家庭。
- 查看和操作被授权的设备。
- 按权限管理家庭成员、房间和设备。
- 退出家庭。

权限建议：

- 创建者：拥有家庭全部管理权限。
- 管理员：拥有大部分家庭和设备管理权限，不可删除创建者。
- 成员：以设备使用为主，部分管理权限受限。

### 3.3 师傅

师傅可由用户绑定并授权调试设备。

主要能力：

- 申请成为师傅。
- 维护师傅资料卡。
- 查看已绑定家庭。
- 查看授权调试家庭。
- 处理家庭邀请消息。
- 在授权有效期内查看和调试设备。
- 查看设备后台高级参数。

### 3.4 后台运营/客服/售后人员

后台人员负责审核、配置、内容维护、设备运维和售后处理。

主要能力：

- 用户管理。
- 家庭/设备/绑定关系管理。
- 师傅资料审核。
- 设备故障和报修处理。
- 广告 Banner、电子说明书、常见问题、安装说明配置。
- 设备参数模板、协议字段、故障码和 OTA 配置。
- 数据看板、日志审计和消息管理。

### 3.5 设备

设备为壁挂炉 4G 温控器，协议文档中设备类型为：

- `type = 5`：壁挂炉。
- `devType = 0`：4G-433。

设备通过 MQTT 与云端通信，协议字段以 `docs/壁挂炉协议最新版本.xlsx` 为准。

## 5. C 端微信小程序功能规划

### 5.1 登录/注册

支持两种登录方式：

- 手机号授权登录/验证码登录。
- 密码登录，支持账号 ID 或手机号。

交互要求：

- 点击登录前校验是否勾选《用户协议》和《隐私协议》。
- 未勾选时弹窗提示。
- 密码登录失败时弹出失败提示。

### 5.2 首页/设备页

用户登录后默认进入设备页。

页面结构：

- 当前家庭信息。
- 家庭所在城市天气。
- 快捷操作：添加设备、扫一扫、邀请、家庭管理、搜索。
- 广告 Banner：后台上传图片和跳转链接，链接非必填。
- 房间选项卡：全屋、已绑定设备的房间、共享设备。
- 设备列表。

设备状态：

- 离线：不可进入详情，点击提示“离线无法查看”；需要记录离线天数，跨过凌晨 12 点加 1 天。
- 在线开机。
- 在线关机。

设备列表字段：

- 产品图片。
- 设备名称。
- 设备 ID。
- 所属房间。
- 实时温度。
- 开关按钮。
- 共享设备需显示所属家庭，不建议列表直接控制，进入详情后控制。

未登录状态：

- 家庭位置变为登录入口。
- 显示“登录查看更多内容”。
- 搜索、快捷操作、房间切换、共享设备隐藏或跳转登录。

设备缺省：

- 当前家庭无设备时展示缺省页。
- 显示“暂无设备，请添加”。
- 点击添加进入添加设备。

### 5.3 搜索

支持按设备名称和设备 ID 模糊搜索。

搜索范围：

- 用户创建的家庭设备。
- 用户加入的家庭设备。
- 用户被分享的设备。

搜索结果：

- 按家庭分组。
- 展示命中设备数量。
- 默认展开，可收起。
- 命中关键字高亮。
- 共享设备归到“共享设备”分组。

### 5.4 添加设备

用户资料明确包含三种添加方式：

- 扫码添加。
- 手动添加。
- 蓝牙添加。

扫码添加：

- 打开相机扫码。
- 获取设备信息后跳转手动添加页。
- 自动带入设备 ID、所属家庭等字段。

手动添加：

- 先进入引导页。
- 引导页配置建议放在 Nacos：步骤、图片链接、描述。
- 输入页字段：
  - 设备 ID：必填。
  - 设备密码：必填。
  - 所属家庭：必填，默认当前家庭。
  - 设备位置：非必填，取家庭下房间。
  - 设备名称：非必填，限 24 字符，默认“家庭名称 + 壁挂炉温控器”。

蓝牙添加：

- 扫描中：提示手机靠近设备。
- 扫描结果：展示设备图片、设备名称。
- 未开启蓝牙：弹窗提示并引导开启。

### 5.5 设备详情

详情页分为三部分：

- 顶部展示。
- 中间操作。
- 底部数据展示。

展示字段：

- 设备名称。
- 所属家庭。
- 所属房间。
- 实时水温。
- 设定温度。
- 工作状态：加热/不加热。
- 实时湿度。

操作能力：

- 开关机。
- 童锁开关。
- 温度设置。
- 模式选择。

模式：

- 舒适。
- 防冻。
- 日计划。
- 周计划。

温度控制规则：

- 舒适模式下允许手动调温。
- 防冻、日计划模式下温度设置按钮禁用。
- UI 提示温度上限：不能超过 60℃。
- UI 提示温度下限：不能低于 5℃。
- 协议层 `devTempset` 范围为 2 到 85，业务层需按产品策略收敛到 UI 范围。

底部数据：

- 温度曲线。
- 湿度曲线。
- 支持日、周、月筛选。
- 日：当天。
- 周：近 7 天。
- 月：近 30 天。

## 8. MQTT 协议规划

用户协议 Excel 已给出 Topic 和字段，本项目应以用户协议为准，前期规划中的 `xywk/{productKey}/{deviceId}/...` 仅可作为模拟器或内部规范，不应直接作为真实硬件协议。

### 8.1 用户协议 Topic

真实设备协议 Topic：

```text
设备SN/dn/s2c/ctl          控制指令下发
设备SN/dn/s2c/ret          平台回复
设备SN/dh/s2c/cloudLock    平台告知设备已上云锁
设备SN/dn/c2s              设备上报
IMEI/getsn                 获取 SN
IMEI/setsn                 设置 SN
IMEI/snSuccess             设备通知平台分码是否成功
```

其中：

- `设备SN` 对应协议字段 `equipNo`。
- 设备上报进入 `设备SN/dn/c2s`。
- 平台控制进入 `设备SN/dn/s2c/ctl`。
- 平台回执进入 `设备SN/dn/s2c/ret`。

### 8.2 核心协议字段

基础字段：

- `snno`：报文序列号。
- `equipNo`：控温器序列号，12 位数字。
- `devAddr`：设备地址，1 到 99。

时间字段：

- `ask3`：查询时间。
- `Day`：星期，1 到 7。
- `Time`：一天内分钟数，0 到 1439。

网关/4G 信息：

- `cmdType`：指令类型。
- `type`：设备类型，5 表示壁挂炉。
- `type2`：设备类型 1。
- `DeviceMode`：设备型号。
- `gwCSQ`：信号强度。
- `gwDevCnt`：设备数量。
- `gwDataInterval`：数据上报间隔，10 到 30000 秒。
- `hardVersion`：硬件版本。
- `gwVersion`：固件版本。
- `mcuVersion`：MCU 版本号。
- `gwIMEI`：4G 模块 IMEI。
- `gwICCID`：4G 卡 ICCID。

壁挂炉/温控器状态：

- `devWtTemp`：给炉子的水温，30 到 80℃。
- `dev8LOnline`：8 路在线状态，bit 位表示。
- `dev8LHeating`：8 路加热需求，bit 位表示。
- `devOnline`：联网状态，0 掉线，1 在线。
- `devRSSI`：无线信号强度。
- `devOnOff`：开关状态，0 关机，1 开机。
- `devRunMode`：运行模式，0 日计划，1 舒适，2 周计划，3 防冻。
- `devTempset`：目标温度，2 到 85。
- `devTemp1`：测量温度，-30 到 100，步长 0.1。
- `devHumi1`：测量湿度，0 到 99。
- `devHeating`：工作状态，0 未启动，1 启动。
- `devchildLock`：童锁，0 解锁，1 上锁。
- `devErr`：故障状态，0 无故障，其他显示故障代码。
- `devType`：子设备类型，0 表示 4G-433。
- `devWtEachTemp`：需求水温，30 到 80℃。

日/周计划：

- `ri-pro`：日计划时段。
- `mon-pro` 到 `sun-pro`：周一到周日时段。

后台高级参数：

- `TempAdj`：温度校正。
- `HumAdj`：湿度校准。
- `TempsetTop`：温控上限。
- `Tolr`：温控容差。
- `Antifreeze`：防冻温度。
- `RFAntifreeze`：接收端防冻温度。
- `wtTempMax`：需求水温上限。
- `wtTempMin`：需求水温下限。
- `wtTempDef`：需求水温默认值。
- `wtTempSen`：需求水温敏感系数。
- `sugMode`：简易模式。
- `backVersion`：后台参数版本号。

OTA：

- `ota4G`：4G 模块 OTA 固件地址。
- `otaMCU1`：主机 MCU 固件 OTA 地址。
- `otaMCU2`：从机 MCU 固件 OTA 地址。

### 8.3 协议适配策略

后端建议增加协议适配层：

```text
真实硬件协议 Topic/Payload
  -> xywk-mqtt-service 协议适配
  -> 统一设备状态模型
  -> Redis / MySQL / RocketMQ / 告警服务
```

统一模型示例：

```text
devOnOff       -> power
devRunMode     -> runMode
devTempset     -> targetTemp
devTemp1       -> currentTemp
devHumi1       -> humidity
devHeating     -> heating
devchildLock   -> childLock
devErr         -> faultCode
gwCSQ/devRSSI  -> signalStrength
gwVersion      -> firmwareVersion
```

控制指令也需要由业务指令转换为协议字段：

```text
开关机       -> devOnOff
模式切换     -> devRunMode
目标温度     -> devTempset
童锁         -> devchildLock
日/周计划    -> ri-pro / mon-pro ... sun-pro
后台参数配置 -> back{}
OTA          -> ota{}
```

## 9. 系统架构

推荐技术路线保持 Spring Cloud：

```text
微信小程序 / 师傅端 / 后台管理端
   |
Spring Cloud Gateway
   |
认证服务 / 用户家庭服务 / 设备服务 / 指令服务 / 师傅服务 / 内容服务 / 售后服务
   |
Redis / MySQL / RocketMQ / XXL-JOB
   |
xywk-mqtt-service
   |
EMQX
   |
壁挂炉 4G 温控器
```

核心服务：

- `xywk-gateway`：统一入口。
- `xywk-auth-service`：登录、Token、账号安全。
- `xywk-user-service`：用户、个人资料。
- `xywk-family-service`：家庭、房间、成员、邀请。
- `xywk-device-service`：设备、绑定、状态、共享、带载设备。
- `xywk-command-service`：控制指令、回执、超时、幂等。
- `xywk-mqtt-service`：EMQX 连接、真实协议解析、Topic 适配。
- `xywk-master-service`：师傅资料、审核、授权、工作台。
- `xywk-content-service`：Banner、说明书、FAQ、安装说明、协议。
- `xywk-after-sales-service`：报修、服务验收、售后记录。
- `xywk-admin-service`：后台聚合接口。
- `xywk-stat-service`：看板、曲线和报表。

## 11. 关键业务流程

### 11.1 设备绑定

```text
用户扫码/手动/蓝牙发现设备
 -> 输入设备 ID 和设备密码
 -> 选择家庭、房间、设备名称
 -> 后端校验设备是否存在、是否已绑定、密码是否正确
 -> 绑定设备到家庭
 -> 设备进入首页列表
```

### 11.2 设备状态上报

```text
设备发布到 设备SN/dn/c2s
 -> EMQX
 -> xywk-mqtt-service
 -> 解析真实协议字段
 -> 映射统一状态模型
 -> 更新 Redis 最新状态
 -> 写入 MySQL 快照/变化日志
 -> 如 devErr 非 0，生成故障
```

### 11.3 用户控制设备

```text
微信小程序操作设备
 -> Spring Cloud Gateway
 -> xywk-command-service 校验权限和参数
 -> 转换为协议字段
 -> 发布到 设备SN/dn/s2c/ctl
 -> 设备执行
 -> 设备上报状态或回执
 -> 后端更新指令状态
```

### 11.4 师傅授权调试

```text
用户绑定师傅
 -> 用户点击授权调试设备
 -> 二次确认
 -> 当前家庭下所有设备授权给师傅 24 小时
 -> 师傅端可查看和调试设备
 -> 到期后自动回收权限
```
