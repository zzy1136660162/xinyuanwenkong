# 鑫源温控中间件 Docker Compose 部署说明

## 1. 启动命令

```bash
docker compose up -d
```

查看状态：

```bash
docker compose ps
```

查看日志：

```bash
docker compose logs -f
```

停止：

```bash
docker compose down
```

如果需要清空所有中间件数据后重新初始化：

```bash
docker compose down
rm -rf docker/mysql/data docker/redis/data docker/rocketmq/broker/store docker/emqx/data
docker compose up -d
```

## 2. 离线镜像下载与导入

Docker 镜像通常不直接通过官方固定 URL 使用 `wget` 下载。推荐方式是在一台有网络的机器上先 `docker pull`，再 `docker save` 成 tar 包，然后把 tar 包放到内网服务器或文件服务器上，目标机器再用 `wget` 下载并 `docker load` 导入。

有网络机器执行：

```bash
chmod +x scripts/save-images.sh
./scripts/save-images.sh
```

会生成：

```text
artifacts/docker-images/xywk-middleware-images.tar
artifacts/docker-images/xywk-middleware-images.tar.sha256
```

Windows PowerShell 执行：

```powershell
.\scripts\save-images.ps1
```

如果 PowerShell 策略拦截脚本，可以只对当前进程放开：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\scripts\save-images.ps1
```

如果需要通过临时 HTTP 服务给其他机器下载：

```bash
cd artifacts/docker-images
python3 -m http.server 8000
```

目标机器下载：

```bash
mkdir -p artifacts/docker-images
wget -P artifacts/docker-images http://有网络机器IP:8000/xywk-middleware-images.tar
wget -P artifacts/docker-images http://有网络机器IP:8000/xywk-middleware-images.tar.sha256
```

目标机器导入：

```bash
chmod +x scripts/load-images.sh
./scripts/load-images.sh
```

Windows PowerShell 导入：

```powershell
.\scripts\load-images.ps1
```

也可以手动导入：

```bash
docker load -i artifacts/docker-images/xywk-middleware-images.tar
```

## 5. 注意事项

- MySQL 初始化脚本只会在 `docker/mysql/data` 为空时执行。
- 如果修改了 Nacos 或 XXL-JOB 初始化 SQL，需要清空 `docker/mysql/data` 后重新启动。
- EMQX 当前只设置了 Dashboard 密码，设备 MQTT 账号、ACL 和认证规则需要在 EMQX 后台或后续配置文件中继续配置。
- RocketMQ 在本机 IDE 连接异常时，检查 `docker/rocketmq/broker.conf` 中的 `brokerIP1` 注释说明。
- 生产环境不建议直接使用这份单机配置，需要补充 TLS、备份、高可用、监控和更严格的账号权限。
